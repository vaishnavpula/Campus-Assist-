# Campus-Assist

A Python-based campus management system designed to manage student information, academic activities, and student expenses through a simple menu-driven interface.

## Overview

Campus-Assist is a modular Python project developed to practice and demonstrate core Python programming concepts through a practical application.

The project uses Object-Oriented Programming (OOP), file handling, classes and objects, and modular programming to organize different student-related functionalities.

## Features

- Student information management
- Student expense tracking
- Academic grade and CGPA calculation
- Python and Java quiz functionality
- Menu-driven interaction
- File-based data storage
- Object-Oriented Programming implementation
- Modular project structure

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
- File Handling
- Python Modules
- Classes and Objects

## How to Run

## 1. Clone the repository

git clone https://github.com/vaishnavpula/Campus-Assist-.git

## 2. Open the project directory

cd Campus-Assist-

## 3. Run the main program

python main.py

### «Make sure Python is installed on your system before running the project.»
